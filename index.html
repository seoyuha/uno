Firebase 연결이 필요해요

  1. Firebase 콘솔에서 Realtime Database를 만들어요. (위치는 싱가포르 asia-southeast1 추천)
  2. Realtime Database의 규칙 탭에 아래 내용을 넣고 게시해요. 다른 게임 규칙이 이미 있다면 "yummyUno" 부분만 추가하세요. 
    {
  "rules": {
    "yummyUno": { ".read": true, ".write": true }
  }
}
  3. 이 HTML 파일 위쪽의 firebaseConfig에 내 앱 설정을 붙여 넣어요. databaseURL이 꼭 들어 있어야 해요.
